# Sample Attribution

The active demonstration is generated by `lib/sample.ts` using the authored material in `data/sample-books.ts`. It contains fictional reading events, progress, chapter labels, passages, and prewritten interpretations. Book titles and author names identify the demonstration's subject matter; passages are NOT quotations from those books. Prewritten interpretations are labeled as demonstrations, not actual model responses. No private account data or API keys are used.

The historical `sample.json` is retained for attribution and reference. It is no longer served by `/api/sample`. It was copied from `yao-weread-skill/reports/generated/ai-founder-sample/weread-report-data.json` in this workspace.
